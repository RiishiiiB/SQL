# LeetCode 607 - Sales Person

## 📌 Problem

Find the names of all salespersons who did not have any orders related to the company named **"RED"**.

## 🧠 Approach

* Identify salespersons who have orders associated with the company `"RED"`.
* Exclude those salespersons from the complete list of salespersons.
* Use table relationships between `SalesPerson`, `Orders`, and `Company`.

## 💡 SQL Concepts Used

* `JOIN`
* `LEFT JOIN`
* `WHERE`
* `NULL` filtering
* Subquery / exclusion logic
